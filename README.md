# Deepak Chakrala — Data Engineer portfolio

A minimalist, responsive portfolio website made with plain HTML, CSS, and JavaScript. No paid hosting, frameworks, build steps, or external services are required. The optional Google Fonts request falls back to system fonts if unavailable.

## IMPORTANT: review before publishing

This is a **draft**, adapted from `Deepak_Chakrala_Data_Engineer_Master_Resume(2).pdf`, not a verified employment record. Your uploaded resume versions contain conflicting employers and employment dates. The experience entries in `index.html` are explicitly marked as draft; **confirm and edit or remove them before publishing**. Confirm the technical tools and responsibilities as well. ## Preview on your computer

Double-click `index.html` to open it in a browser. For a local web server (optional), run `python -m http.server 8000` inside this folder, then visit `http://localhost:8000`.

## Publish for free with GitHub Pages

1. Sign in or create a free account at https://github.com/.
2. Create a **public** repository named `YOUR_USERNAME.github.io`, replacing `YOUR_USERNAME` with your actual GitHub username.
3. Upload the files `index.html`, `styles.css`, `script.js`, and optionally this `README.md` to the **root** of the repository. Commit them to the `main` branch.
4. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select `main`, folder `/ (root)`, and save.
5. After GitHub Pages publishes the site, open `https://YOUR_USERNAME.github.io/`. Publication can take several minutes.
6. To update the site, edit the files in your GitHub repository and commit the changes.

GitHub Pages is free for public repositories on GitHub Free. A custom domain is optional and usually costs money. Your default `github.io` URL is free.
