# Deepak Chakrala — From Curiosity to Clarity

A responsive, dark, animated Data Engineer portfolio for free GitHub Pages hosting.

## Preview without publishing
Open `index.html` in Chrome, Edge, or Firefox. Keep `index.html`, `styles.css`, and `script.js` in the same folder. Google Fonts require an internet connection; the site has system-font fallbacks.

## Publish to your existing GitHub Pages repository
1. Visit https://github.com/Deepak-Data-Engineer/Deepak-Data-Engineer.github.io
2. Replace the root `index.html`, `styles.css`, and `script.js` with the files in this folder, then commit the changes.
3. Wait for GitHub Pages to redeploy, then visit https://deepak-data-engineer.github.io/ .

**Do not publish until you've approved the preview.** Publishing replaces the existing design.
